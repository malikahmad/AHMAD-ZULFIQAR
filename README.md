- FastAPI-based application backend.

### 🛡️ 2. DeepGuard AI – Transformer-Based Deepfake Detection

**Deep Learning | Transformers | Computer Vision | Grad-CAM++**

An AI-powered deepfake detection system designed to classify images as Real or Fake and provide visual explanations of model predictions.

**Key Highlights:**
- Transformer-based image classification.
- Real vs Fake image prediction.
- Grad-CAM++ visual explainability.
- Confidence score visualization.
- Model performance evaluation.

🔗 **[View Project Repository](https://github.com/malikahmad/DeepGuard-AI-Transformer-Based-Deepfake-Detection-Explainable-AI)**

---

### 📚 3. Institute Intelligent Document Assistant

**Generative AI | RAG | LLMs | FAISS | Flask**

An intelligent document assistant that allows students to upload PDF documents and ask questions using Retrieval-Augmented Generation.

**Key Highlights:**
- PDF document processing.
- Semantic search and embeddings.
- FAISS vector database.
- LLM-powered question answering.
- Document-grounded responses.
- Source and page citations.
- Flask-based web application.

🔗 **[View Project Repository](https://github.com/malikahmad/Institute-Intelligent-Document-Assistant-AI-Powered-RAG-Chatbot)**
